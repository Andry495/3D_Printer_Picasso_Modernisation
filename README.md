# Модернизация 3Д принтера Picasso

Документация проекта по модернизации принтера **Picaso 3D Designer XL**:
- переход на современную электронику;
- конфигурация с **одним хотэндом**;
- подготовка к работе с **Klipper + Raspberry Pi 4B**;
- список комплектующих, датчиков и рекомендации по закупке.

## Состав проекта

- `Комплект_электроники_3D_принтер.md`  
  Основная техническая спецификация по электронике, прошивке и конфигурации.

- `Список_покупок_электроники.md`  
  Актуальный список запчастей с количеством и ориентировочной стоимостью.

- `Где_купить_компоненты.md`  
  Поисковые запросы и ориентиры по магазинам (РФ и AliExpress).

## Текущая конфигурация

- Плата: **BigTreeTech Octopus v1.0.1**
- Хост: **Raspberry Pi 4B**
- Прошивка: **Klipper**
- Головка: **один хотэнд (E3D V6 или аналог)**
- Датчики:
  - **BLTouch** (автолевелинг + ноль по Z для сопла)
  - **датчик окончания филамента**
  - оптические концевики по осям

## Оценка бюджета

По текущему списку: примерно **$424-638**  
(около **33 900-51 200 ₽**, зависит от магазина и курса).

## Примечания

- Для первого запуска Klipper рекомендуется:
  1. подготовить Raspberry Pi (MainsailOS/Fluidd);
  2. прошить Octopus;
  3. настроить `printer.cfg` и откалибровать BLTouch;
  4. проверить датчик окончания филамента.

- Проект ведется как рабочая документация и регулярно обновляется.
