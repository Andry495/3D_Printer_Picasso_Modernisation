- **Рабочая папка с документацией и Git:** `D:\project\3D_printer`

Раньше в родительском каталоге **`D:\project`** случайно оказался **отдельный** Git (индексировались другие проекты вроде Agisoft/Android). **Документация принтера к тому репозиторию не относится.** Для принтера используйте **только** `D:\project\3D_printer`.

## Команды синхронизации

Выполнять в **`D:\project\3D_printer`** (PowerShell или `cmd`):

```powershell
cd D:\project\3D_printer
git fetch origin
git status
git pull origin main
```

Отправить свои правки на GitHub:

```powershell
git add -A
git status
git commit -m "Краткое описание изменений на русском или английском"
git push origin main
```

Если **`git push`** запросит авторизацию — используйте **Personal Access Token** (GitHub → Settings → Developer settings) или **SSH-ключ**, настроенный для GitHub.
